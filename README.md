## 구조 도식

02번 탭의 모달리티 항목을 펼치면 손으로 그린 인라인 SVG 도식이 나옵니다 —
저분자와 항체의 크기 비교 · IgG 구조 · 이중항체 T세포 인게이저 · ADC 4단계 작용 ·
PD-1/PD-L1 차단 · CAR 도메인과 자가유래 제조 흐름 · 유전자치료 in vivo/ex vivo ·
ASO/siRNA/mRNA 비교 · 오리지널 대 시밀러 개발 경로.
04번 탭에는 Kaplan-Meier 곡선과 포레스트 플롯 읽는 법이 도식으로 들어 있고,
05번 탭에는 항암(교체)과 비항암(강화)의 라인 개념 차이, 후기 라인에서 1차로 올라오는 3개 관문 도식이 있습니다.

## 수치 신뢰도 표기

모든 수치에 태그가 붙어 있습니다.

- **확인** — 출처와 기준연도가 확인된 수치
- **추정** — 사전지식으로 채운 내용. 사용 전 원출처 확인 필요
- **구자료** — 2016~2023년 자료. 추세 파악용
- **미확인** — 조사했으나 확인 실패
