## 수치 신뢰도 표기

모든 수치에 태그가 붙어 있습니다.

- **확인** — 출처와 기준연도가 확인된 수치
- **추정** — 사전지식으로 채운 내용. 사용 전 원출처 확인 필요
- **구자료** — 2016~2023년 자료. 추세 파악용
- **미확인** — 조사했으나 확인 실패

## 알려진 한계

- 유니버스의 **6자리 종목코드와 시장 구분은 미검증**입니다. KRX 상장법인 목록으로 대조가 필요합니다
- **종목별 시가총액은 포함하지 않았습니다**
- 데이터 기준일은 **2026년 8월 28일**입니다
