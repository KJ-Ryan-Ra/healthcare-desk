## 분자 구조

06번 탭의 저분자 약물 카드에는 **2D 화학구조**가 들어 있습니다. 위키피디아 인포박스의 SMILES를
RDKit으로 분자식 대조 검증한 뒤 직접 렌더링한 것으로, **검증에 실패한 구조는 그리지 않았습니다.**
탄소·결합은 `currentColor`를 상속해 다크/라이트 테마를 따라가고, 헤테로원자만 고정 색을 씁니다.
항체·ADC·CAR-T·유전자치료제처럼 2D 구조로 표현되지 않는 계열은 대신 분자 포맷 사양
(아이소타입·DAR·링커/페이로드·벡터·발현 세포주·투여·생산)을 싣고, 계열 구조 도식은 02번 탭으로 연결했습니다.

## 모달리티 구조 도식

02번 탭의 모달리티 항목을 펼치면 손으로 그린 인라인 SVG 도식이 나옵니다 —
저분자와 항체의 크기 비교 · IgG 구조 · 이중항체 T세포 인게이저 · ADC 4단계 작용 ·
PD-1/PD-L1 차단 · CAR 도메인과 자가유래 제조 흐름 · 유전자치료 in vivo/ex vivo ·
ASO/siRNA/mRNA 비교 · 오리지널 대 시밀러 개발 경로.
04번 탭에는 Kaplan-Meier 곡선과 포레스트 플롯 읽는 법이 도식으로 들어 있고,
05번 탭에는 항암(교체)과 비항암(강화)의 라인 개념 차이, 후기 라인에서 1차로 올라오는 3개 관문 도식이 있습니다.

## 수치 신뢰도 표기

모든 수치에 태그가 붙어 있습니다.

- **확인** — 출처와 기준연도가 확인된 수치
- **추정** — 사전지식으로 채운 내용. 사용 전 원출처 확인 필요
- **구자료** — 2016~2023년 자료. 추세 파악용
- **미확인** — 조사했으나 확인 실패
